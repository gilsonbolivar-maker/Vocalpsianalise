# Vocalpsianalise

Apoio à psicóloga durante a sessão: o programa ouve a conversa, transcreve e aponta sinais ligados aos critérios do DSM-5-TR.

**O programa não dá diagnóstico.** Ele sugere sinais. Quem avalia, confirma ou descarta é sempre a psicóloga.

## Regras do projeto

1. **Consentimento primeiro.** O programa só começa a ouvir depois que a psicóloga confirma que o paciente foi avisado e concordou.
2. **Sigilo.** Nenhum áudio, transcrição ou dado de paciente vai para este repositório. Aqui fica só o código.
3. **Apoio, não decisão.** Toda sugestão aparece como "sinal a investigar", com o trecho da fala que gerou o sinal.
4. **Testes só com dados fictícios** até a ferramenta ser validada por profissionais.

## Etapas

1. **Transcrição no aparelho.** Ouvir a sessão e transformar a fala em texto, sem enviar o áudio para a internet.
2. **Sinais por palavras-chave.** Marcar trechos ligados a critérios do DSM, por exemplo sono, apetite, humor, ideação de risco.
3. **Ligação com o Anamnese PSI.** Levar os sinais confirmados para a ficha do paciente no app Anamnese PSI.
4. **Avaliação das psicólogas.** Testar com o grupo e decidir se vale uma análise mais avançada.
